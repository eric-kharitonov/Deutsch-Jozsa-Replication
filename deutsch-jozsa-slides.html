The Problem

Constant or Balanced — and how do you know?

You have a black-box function f that returns 0 or 1.
You are told it is one of two types:

CONSTANT
Returns the same value (0 or 1) for every input
BALANCED
Returns 0 for exactly half the inputs, 1 for the other half

Classical

Worst case: must check more than half of all possible inputs before you can be certain.

Quantum

1 query.
Every time.

That's the promise of Deutsch-Jozsa.

f(00000)=0   f(00001)=0   f(10101)=0   ...   f(11111)=0

Constant oracle

The function returns the same value for every input.

The ancilla flip just swaps constant-0 to constant-1 — still constant either way.

If the second coin flip returns 1 we exit early. The oracle does nothing to the input qubits. That is the constant case.

2. The Oracle

Balanced Function — The Conjugate Pattern
on_states = np.random.choice(
    range(2**num_qubits),
    2**num_qubits // 2,   # exactly half
    replace=False,
)

def add_cx(qc_dj, bit_string):
    for qubit, bit in enumerate(reversed(bit_string)):
        if bit == "1":
            qc_dj.x(qubit)
    return qc_dj

for state in on_states:
    qc_dj = add_cx(qc_dj, f"{state:0{num_qubits}b}")
    qc_dj.mcx(list(range(num_qubits)), num_qubits)
    qc_dj = add_cx(qc_dj, f"{state:0{num_qubits}b}")

Half the states flip the ancilla. Half do not. That is what makes it balanced.

X gates ON

Flip qubits so this state looks like |11111⟩

mcx(...)

Multi-controlled X fires — ancilla flips for this state only

X gates OFF

Restore qubits — same flips undo each other

Why transpile?

Real quantum hardware supports only a small set of native gates (CX, Rz, SX) on specific qubit pairs.

Transpilation rewrites your circuit into those native gates and routes operations across the chip's physical qubit topology.

More gates, same result — the hardware just needs smaller steps.

Status: JobStatus.RUNNING  =>  Status: JobStatus.DONE  =>  ✓

Why shots = 1?

Deutsch-Jozsa is deterministic. Quantum interference guarantees the same correct answer on every single run.

One shot is sufficient.

The USE_SIMULATOR flag lets you switch between the noisy local simulator and real IBM hardware without touching the logic.

Why does it work?

Constant: all inputs pick up the same phase. The second Hadamard layer constructively interferes everything back into |00000⟩.

Balanced: inputs pick up opposite phases. Interference cancels the |00000⟩ amplitude entirely. You always get a non-zero result.

One query. Certain answer.
